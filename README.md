# Windows Persistence Techniques

A single-page, glassmorphism-styled reference of Windows persistence mechanisms. Each technique card includes classification, location, description, and a practical command/script example.

## Live Site

Hosted on GitHub Pages: **https://zrnge.com/win-persistence**

## Features

- 44+ Windows persistence techniques
- Practical examples for every technique
- Syntax highlighting for commands, registry paths, and flags
- Search and filter by permission level or launch type
- Expand/collapse examples
- Responsive layout for desktop, tablet, and mobile
- Reduced-motion support
